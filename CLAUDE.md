Пользователь пишет по-русски, неформально. Отвечай коротко и по делу.

## Что за проект
Каталог HTML5-игр на русском как замена Яндекс Играм (у Яндекса сбои). Название — **Gamely** (бывший «Игродром»),
домен **playgamely.ru** (gamely.ru занят). По-русски «Gamely» не склоняется: «на Gamely», «аккаунт Gamely».
Внутренние имена со словом igrodrom (папка /opt/igrodrom, база igrodrom.db, docker-том, ключи localStorage, протокол SDK,
`IgrodromHost`, `Igr`) оставлены намеренно: их смена сломала бы данные и сохранения. В SDK публичное имя `Gamely`,
`Igrodrom` — запасное.
Правила: сайт похож на Яндекс Игры, на сайте нет разговоров о заработке (магазин монеток с ценами — можно, это решение
пользователя), дизайн без «ИИ-шаблонности».
Сайт работает на https://playgamely.ru (см. «Продакшен»).

`npm run build:sdk` и `npm run build:catalog` после правок SDK/каталога (тесты ругаются, если устарело).
