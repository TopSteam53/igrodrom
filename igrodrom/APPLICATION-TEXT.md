# Текст заявки в рекламные сети

Шаблон. Подставьте значения в [скобках]. Не завышайте трафик: сеть сверяет цифры
с аналитикой, и ложные данные — частая причина отказа и блокировки аккаунта.
Если трафика пока нет, так и пишите: «площадка на старте». Часть сетей откажет, часть
возьмёт в тестовом режиме — для этого заявок и надо минимум три.

---

**Тема:** Заявка на подключение площадки [домен] — каталог HTML5-игр

Здравствуйте!

Прошу рассмотреть подключение площадки [домен] к вашей рекламной сети.

**О площадке.** «Игродром» — каталог браузерных HTML5-игр, куда независимые разработчики
загружают свои игры. Игры запускаются в браузере без установки, на телефоне и ПК.
Площадка запущена [дата], на старте в каталоге [N] игр. Аудитория — [возраст, интересы],
основные источники трафика: [Telegram-каналы, соцсети, прямые заходы].

**Текущий трафик.** [N] сессий и [N] уникальных пользователей за последние [30] дней
по данным [Яндекс Метрики / другой системы]. Скриншот отчёта приложу. Если площадка
ещё не набрала трафик, пишу об этом прямо и готов подключиться в тестовом режиме.

**Размещение рекламы.** Планирую:
- баннер под окном игры (адаптивный);
- межстраничный блок при запуске игры и между уровнями, не чаще [1 раза в 3 мин];
- rewarded-видео по желанию игрока (за награду в игре), если ваша сеть поддерживает формат.
Реклама не перекрывает игру без возможности закрыть, на детские игры не ставится
без соблюдения требований к детской аудитории.

**Контент и модерация.** Игры загружают сторонние авторы. Перед публикацией каждая игра
проходит ручную проверку: на вредоносный код, на запрещённый контент (18+, азарт,
насилие, экстремизм), на нарушение авторских прав. Есть форма жалобы для правообладателей;
спорные игры снимаются в течение [24] часов. Игры запускаются в изолированном
iframe с ограниченными правами.

**Вопросы, которые прошу уточнить:**
1. Минимальный трафик для подключения и условия тестового режима.
2. Допускается ли размещение рекламы внутри игр сторонних авторов (UGC).
3. Доступные форматы и ориентировочный eCPM для игрового трафика из РФ.
4. Условия выплат: минимальная сумма, периодичность, валюта, с кем заключается договор
   (самозанятый / ИП / ООО), документы.
5. Кто отвечает за маркировку рекламы (ERID) и передачу данных в ОРД.
6. Запрещённые тематики и ограничения для детской аудитории.

**Контакты:** [имя], [email], [Telegram], [телефон].
Владелец площадки: [ФИО / ИП / самозанятый, ИНН].

С уважением, [имя].
