# Игродром — прототип площадки HTML5-игр

Статический прототип для демо-ролика. Сборка не нужна: откройте `index.html` в браузере
(или `python3 -m http.server` в этой папке).

Что есть: каталог с жанрами, 3 играбельные игры, окно игры с рекламным блоком,
загрузка своей `.html` игры (localStorage), калькулятор дохода разработчика (доля 70%).

Чего нет (это и есть настоящая работа): бэкенд, аккаунты, модерация, рекламная сеть, выплаты, SDK.
