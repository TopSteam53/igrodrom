## Что за проект
Каталог HTML5-игр на русском как замена Яндекс Играм (у Яндекса сбои). Название — **Gamely** (бывший «Игродром»),
домен **playgamely.ru** (gamely.ru занят). По-русски «Gamely» не склоняется: «на Gamely», «аккаунт Gamely».
Внутренние имена со словом igrodrom (папка /opt/igrodrom, база igrodrom.db, docker-том, ключи localStorage, протокол SDK,
`IgrodromHost`, `Igr`) оставлены намеренно: их смена сломала бы данные и сохранения. В SDK публичное имя `Gamely`,
`Igrodrom` — запасное.
Правила: сайт похож на Яндекс Игры, на сайте нет разговоров о заработке (магазин монеток с ценами — можно, это решение
пользователя), дизайн без «ИИ-шаблонности».
Сайт работает на https://playgamely.ru (см. «Продакшен»).

`npm run build:sdk` и `npm run build:catalog` после правок SDK/каталога (тесты ругаются, если устарело).

## Что уже есть
- «Совёнок» (`public/games/sova`): физическая головоломка «убери блоки», свой движок (порт Box2D-Lite, `physics.js`),
  2.5D-спрайты из `scripts/blender/sova.py`. Уровни — текстовые карты в `levels.js`; `scripts/sova-levels.mjs` решает их
  (минимум касаний, решение для подсказки → `solutions.js`, проверка устойчивости к паузам игрока), `scripts/sova-generate.mjs`
  предлагает новые. После правки уровней или физики — перезапустить решатель; `test/sova.test.js` это проверяет.
- Каталог из 23 игр (новые — «Совёнок» и «Огонёк», выживалка в духе Vampire Survivors, `public/games/ogonek`) (`public/games/*`, у каждой meta.json), статический `catalog.json` для GitHub Pages.
- «Звёздный патруль» (`public/games/starpatrol`): спрайты, фон, обложка и иконка отрендерены в Blender 5.2
  скриптом `scripts/blender/starpatrol.py` (blender --background --python … -- public/games/starpatrol [имена]).
- «Огонёк» в 2.5D: спрайты леса и врагов из `scripts/blender/ogonek.py` (камера 45°, ловец теней) → `public/games/ogonek/img`;
  огонёк, свет и снаряды рисуются в игре. Волны по 45 с, каждая 5-я — босс (4 разных), рассвет после 15-й; события в волнах
  (светлячки, костёр, золотая тень, алтарь), рывок, фонари, превращения оружия, 3 героя. Лимиты для телефонов: врагов ≤130,
  искр ≤80 (лишние сливаются). Сохранение `v:1` совместимо.
- Аккаунты игроков, заявки разработчиков, загрузка игр ZIP, модерация; роли: игрок, разработчик, модератор
  (назначает владелец в кабинете), владелец (`ADMIN_EMAILS`).
- Свой SDK (`public/sdk/v1.js`) и совместимость с Яндекс SDK (`public/sdk/yandex.js`): игры из Яндекс Игр
  загружаются без правок. Облачные сохранения, таблицы рекордов, монетки, отзывы (в Яндекс-SDK — leaderboards и feedback).
- Почта (`server/mail.js`, `SMTP_URL`): подтверждение адреса и сброс пароля; без SMTP письма идут в лог.
- Монетки — валюта сайта: покупка через ЮKassa (`server/economy.js`, пока без ключей — магазин выключен), 50 в подарок
  новичку, за вход — серия 7 дней (5…20), выдача владельцем. За время в игре НЕ начисляются (решение пользователя 20.10.2026).
  Тратятся в играх через SDK с подтверждением игрока. Отзывы с модерацией. `server/rewards.js`: серия входов, 13 достижений,
  турнир недели (игру выбирает владелец в админке, призы 150/100/50 монеток, страница `/tournament`), приглашение друга
  `/?invite=<код>` (30 + 20 монеток после подтверждения почты). Рубли игрокам не выплачиваем.
- Страница студии `/developer/<id>` (текст в HTML, кнопка «Связаться» из публичного контакта студии). Приглашения авторов
  `/developers?ref=<код>` (`server/devref.js`): учёт на сервере и в админке («пригласил …»), блок в кабинете убран по решению владельца 24.10.2026. Владелец ставит игру
  первой в подборку на главной кнопкой в админке. Цели Метрики — `Igr.goal()` в `public/app.js`.
- SDK подменяет `window.caches`, если он бросает ошибку в песочнице: иначе игры на Unity 6 не загружаются.
- Аватарки: 16 плоских зверей в SVG (`scripts/avatars-svg.mjs`; 3D-версия не понравилась пользователю) или своя с проверкой модератором.
- Витрина (`server/shop.js`, вкладка профиля «Витрина»): за монетки 7 рамок аватарки, 6 цветов имени, 8 зверей (17–24.svg);
  бесплатно — достижение рядом с именем в отзывах. Видно в шапке, профиле, отзывах, рекордах, турнире, странице студии.
- Кабинет разработчика: карточка игры как в консоли Яндекса, картинки, обновление сборки через модерацию, страница студии
  (`developer.html`). Тестовый запуск `/cabinet-test?id=…` (`cabinet-test.html`): игра по подписанной ссылке `/test-run/…`,
  куда сервер вставляет журнал `server/test-console.js` (console, ошибки, 404 файлов), рядом — журнал вызовов SDK;
  сохранения, рекорды и монетки там в памяти страницы, в статистику не идёт. Скачивание сборки и картинок ZIP-архивом
  (`GET /api/games/<id>/download?part=build|next|media`, запись ZIP — `server/zip.js`). Админка `admin.html`: обзор, пользователи, блокировка, модерация, платежи, журнал, команда.
- Реклама через `.env` (`ADS_PROVIDER`: none/test/yandex/vk/google), ads.txt, счётчик показов, страницы
  contacts/terms/privacy (шаблоны, юридически не проверены).
- Тёмная тема, шрифты Unbounded + Onest.
- Чистые адреса: игра `/game/<slug>` (slug выдаётся при публикации и не меняется, `server/slug.js`), категория
  `/category/<slug>`, страницы без `.html`; старые `game.html?id=`, `?category=`, `*.html` → 301. Статика на GitHub Pages
  остаётся на старых адресах. Сервер кладёт в HTML карточки, категории, текст игры и JSON-LD (Яндекс не выполняет JS).
- SEO и превью ссылок: robots.txt, sitemap.xml, og-теги вставляет сервер. Картинки превью `og.jpg` (у игр и общая)
  рендерит `scripts/og-images.ps1`: для новой демо-игры его нужно запустить. Своя страница 404.

## Скиллы
- `.claude/skills/frontend-design` — план дизайна без шаблонности (Anthropic).

  «Context loading did not run» и читает DESIGN.md напрямую — это нормально. Не работают только `live` и `generate`.
- Больше 2–3 скиллов не ставить: каждый ест контекст.

## Правила работы
- Разработка и пуши только в ветку `claude/yandex-games-alternative-uzcl2b`. PR не создавать без просьбы.
- Историю git не переписывать без подтверждения. Папка `docs/` в `.gitignore`.
- Почта пользователя только для авторства, никуда её не отправлять.
- Не убивать процессы через `pkill -f`/`pgrep -f`.
- Игры: без localStorage/alert/внешних URL, сохранения через SDK; проверять на десктопе и мобильном.
