## Что за проект
Каталог HTML5-игр на русском как замена Яндекс Играм (у Яндекса сбои). Рабочее имя «Игродром» — пользователю
не нравится, нужно английское название, он его ещё не назвал. Не гадай, пока не скажет.
Правила: сайт похож на Яндекс Игры, на сайте нет разговоров о деньгах/заработке, дизайн без «ИИ-шаблонности».
Хостинг и домен ещё не куплены — сначала доводим сайт.

## Стек и запуск
Node.js ≥ 22.13, без зависимостей (`http`, `node:sqlite`). `npm start` → localhost:3000, `npm test` (73 теста),
`npm run build:sdk` и `npm run build:catalog` после правок SDK/каталога (тесты ругаются, если устарело).
Подробности: README.md, дизайн: DESIGN.md, настройки: `.env.example`.

## Что уже есть
- Каталог из 21 игры (`public/games/*`, у каждой meta.json), статический `catalog.json` для GitHub Pages.
- «Звёздный патруль» (`public/games/starpatrol`): спрайты, фон, обложка и иконка отрендерены в Blender 5.2
  скриптом `scripts/blender/starpatrol.py` (blender --background --python … -- public/games/starpatrol [имена]).
- Аккаунты игроков, заявки разработчиков, загрузка игр ZIP, модерация; роли: игрок, разработчик, модератор
  (назначает владелец в кабинете), владелец (`ADMIN_EMAILS`).
- Свой SDK (`public/sdk/v1.js`) и совместимость с Яндекс SDK (`public/sdk/yandex.js`): игры из Яндекс Игр
  загружаются без правок. Облачные сохранения, таблицы рекордов, монетки, отзывы (в Яндекс-SDK — leaderboards и feedback).
- Почта (`server/mail.js`, `SMTP_URL`): подтверждение адреса и сброс пароля; без SMTP письма идут в лог.
- Монетки: 1 за минуту в игре (до 60 в день), тратятся в играх через SDK с подтверждением игрока. Отзывы с модерацией.
- Реклама через `.env` (`ADS_PROVIDER`: none/test/yandex/vk/google), ads.txt, счётчик показов, страницы
  contacts/terms/privacy (шаблоны, юридически не проверены).
- Тёмная тема, шрифты Unbounded + Onest.

## Правила работы
- Разработка и пуши только в ветку `claude/yandex-games-alternative-uzcl2b`. PR не создавать без просьбы.
- Историю git не переписывать без подтверждения. Папка `docs/` в `.gitignore`.
- Почта пользователя только для авторства, никуда её не отправлять.
- Не убивать процессы через `pkill -f`/`pgrep -f`.
- Игры: без localStorage/alert/внешних URL, сохранения через SDK; проверять на десктопе и мобильном.
