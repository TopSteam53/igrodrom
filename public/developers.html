Как опубликовать HTML5-игру в каталоге Игродрома.

Как опубликовать

  1. Зарегистрируйтесь и подайте заявку на аккаунт разработчика: расскажите о себе и своих играх, оставьте контакт. Модератор проверит заявку.
  2. После одобрения в кабинете разработчика откроется загрузка игр.
  3. Загрузите игру: ZIP-архив с index.html или один HTML-файл.
  4. Добавьте описание, правила, категорию и возрастную метку.
  5. Игра уходит на модерацию. После проверки она появится в каталоге, а если нет — в кабинете будет указана причина.

Требования к игре

  • index.html — в корне архива или в единственной папке внутри него.
  • Ресурсы подключаются относительными путями: img/hero.png, а не /img/hero.png.
  • Архив — до 100 МБ (после распаковки — до 300 МБ, до 5000 файлов), одиночный HTML — до 5 МБ. Сжатые сборки Unity (.br, .gz) отдаются с нужными заголовками.
  • Обложка: положите в корень архива cover.png, cover.jpg, cover.webp или cover.svg в пропорции 16:9.
  • Иконка: icon.png, icon.webp или icon.svg, квадрат. Её показывают маленькой (от 48 px), поэтому без текста — один крупный узнаваемый символ игры.
  • Игра должна работать и на компьютере, и на телефоне: мышь, клавиатура и касания.
  • Игра запускается в изолированной песочнице: localStorage, cookie, alert и всплывающие окна недоступны. Прогресс и рекорды сохраняйте через Игродром SDK.

Игра с Яндекс Игр

Загрузите тот же ZIP-архив, что загружали в консоль Яндекс Игр, — пересобирать ничего не нужно. У Игродрома есть свой SDK с тем же API, что у Яндекса: при загрузке ссылки на https://yandex.ru/games/sdk/v2 и /sdk.js начинают вести на него.

  • Работает как на Яндексе: YaGames.init(), облачные сохранения player.getData/setData, статистика getStats/setStats/incrementStats, getStorage(), environment (язык — русский), deviceInfo, LoadingAPI.ready(), GameplayAPI, события on/off, screen.fullscreen, getFlags.
  • localStorage тоже работает: в песочнице SDK подменяет его хранилищем, которое сохраняется вместе с прогрессом. Читайте его после YaGames.init() — до подключения он может быть ещё пустым.
  • Реклама: полноэкранная пока не показывается (onClose(false)), за просмотр видео награда выдаётся сразу.
  • Пока заглушки — игра не упадёт, но функции нет: лидерборды (пустая таблица), покупки (каталог пуст), бонусы, отзывы, ярлык на рабочий стол, мультиплеер, вход через Яндекс.
  • Если у игрока есть аккаунт Игродрома, player.getName() вернёт его имя, а getMode() — пустую строку, как у вошедшего на Яндексе.

Что не пройдёт модерацию

  • Чужие игры и чужая графика без прав на них.
  • Вредоносный код, майнинг, попытки выйти за пределы песочницы.
  • Азартные игры на деньги, экстремизм, контент 18+ без соответствующей метки.
  • Неработающие игры: чёрный экран, ошибки при запуске, невозможность пройти начало.

Сохранения: Игродром SDK

Игра запускается в песочнице, где localStorage и cookie недоступны. Чтобы сохранять прогресс и рекорды, подключите SDK — он передаст сохранение площадке, и оно будет храниться за игроком.

<script src="/sdk/v1.js"></script>
<script>
  let progress = { level: 1, coins: 0 };

  Igrodrom.init().then(async (sdk) => {
    const saved = await sdk.data.get();   // null, если сохранения нет
    if (saved) progress = saved;
    startGame(progress);

    // Сохраняйте по событиям: уровень пройден, покупка, конец раунда.
    onLevelComplete(() => sdk.data.set(progress));
    sdk.game.ready();                     // игра загрузилась и готова к игре
  });
</script>
  • sdk.data.get() — сохранение игрока или null.
  • sdk.data.set(value) — записать. Любое JSON-значение до 200 КБ. Частые вызовы SDK склеивает и отправляет не чаще раза в секунду — последнее значение не потеряется.
  • sdk.data.clear() — удалить сохранение.
  • sdk.environment.host — "igrodrom" на площадке, "standalone" вне её.
  • sdk.player — { anonymous, name, id }: вошёл ли игрок, его имя и постоянный id для вашей игры.
  • sdk.game.ready(), sdk.game.start(), sdk.game.stop() — игра загрузилась, игровой процесс начался и остановился.
  • sdk.ads.fullscreen() → { shown } и sdk.ads.rewarded() → { rewarded } — реклама. Пока рекламы нет: полноэкранная не показывается, награда выдаётся сразу. Вызывайте их уже сейчас, тогда реклама появится в игре без обновления.

Сначала прочитайте сохранение, потом начинайте записывать: иначе первое действие игрока может затереть старый прогресс.

Вне площадки — когда вы открываете игру у себя на компьютере — SDK сохраняет в localStorage, а если он недоступен, в память. Игра работает одинаково. Для отладки без интернета скачайте sdk/v1.js и подключите локальную копию; при загрузке на площадку верните путь /sdk/v1.js.

У гостя сохранения привязаны к браузеру. Когда игрок входит в аккаунт, прогресс переезжает в него и становится доступен на всех его устройствах.
